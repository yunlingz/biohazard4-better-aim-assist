# Repository guidance

Read [DEVELOPMENT_CONTEXT.md](DEVELOPMENT_CONTEXT.md) before changing this mod.
It is the shared handoff for Codex, Claude Code, and maintainers; keep the full
development history there rather than duplicating it in this file.

After meaningful changes, update that context with the version, decisions,
validation evidence, and pending work. Follow current user instructions and
inspect current source when they differ from historical notes.
