# Repository guidance

Read [DEVELOPMENT_CONTEXT.md](DEVELOPMENT_CONTEXT.md) before changing this mod.
It contains the requirements, architecture, development history, validation
evidence, known limits, and maintenance workflow. Use [README.md](README.md) for
player-facing behavior and instructions.

Keep `DEVELOPMENT_CONTEXT.md` current after meaningful development work. Distinguish
saved code, offline validation, and user-tested gameplay versions. Current user
instructions and source take precedence over historical notes.
